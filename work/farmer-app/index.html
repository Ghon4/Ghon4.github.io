Farmer App

Mozare3

Contract-farming app offering financial assistance, materials and agricultural extension services to farmers, with electronic account statements for tracking financial transactions.

  • Flutter
  • GetX
  • Dio
  • Retrofit
  • DI

Key contributions

  • Led delivery of core mobile features (e-wallet balance, in-app commerce, analytics) for 10K+ active farmers.
  • Re-architected the legacy codebase to Clean Architecture + GetX, cutting average screen load time ~35%.
  • Designed and shipped CI/CD pipelines (CodeMagic, Fastlane), reducing release time from 2 days to under 30 minutes per build.
  • Hardened security of user and financial data (token rotation, encrypted local storage, Sentry), driving production crashes down 60%.
  • Dio and Retrofit HTTP clients, dependency injection with injectable, and JSON serialization with json_annotation / json_serializable.
  • Clean Code principles, environment configuration via env files, and static analysis with Flutter Lints.

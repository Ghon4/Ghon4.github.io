Qoodz Manager

MakanE

A full point-of-sale (POS) application for Qoodz restaurant and café partners, with promo-code redemption and customer-offer management that makes it easy to exchange and track offers.

  • Flutter
  • BLoC
  • Firebase
  • Dio

Key contributions

  • Built the full offline mode: sales keep working without an internet connection and sync once the device is back online.
  • Revamped the app's design and functionality for an improved partner experience.
  • Added new features to simplify offer redemption and tracking.
  • Integrated Firebase for real-time data synchronization and analytics.
  • Optimized app performance for seamless business operations.
  • Enhanced UI/UX to ensure smooth usability for restaurant partners.
  • Implemented the BLoC state management pattern and Clean Architecture for a well-structured, maintainable codebase.
  • Integrated a payment gateway for secure, seamless transactions within the app.
  • Used Sentry for issue tracking to proactively resolve bugs and improve app reliability.
  • Leveraged animations to enhance the user interface and provide an engaging user experience.
  • Used Dio for efficient network requests and data retrieval.

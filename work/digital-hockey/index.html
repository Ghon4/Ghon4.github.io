Digital Hockey

Swiss Digital Hockey AG

The companion app for hockey fans, players and clubs, built as a white-label app: multiple branded builds ship from one codebase.

  • Flutter
  • BLoC
  • Socket.io
  • RevenueCat
  • GoRouter

Key contributions

  • White-label architecture: multiple branded builds from one codebase via Android product flavors and iOS schemes.
  • Increased user engagement with real-time chat, live matches and other features using Socket.io.
  • Integrated RevenueCat for in-app purchases and subscriptions, enabling premium features and revenue generation.
  • Implemented the BLoC state management pattern and Clean Architecture for a well-structured, maintainable codebase.
  • Integrated a payment gateway for secure, seamless transactions within the app.
  • Used Sentry for issue tracking to proactively resolve bugs and improve app reliability.
  • Leveraged animations to enhance the user interface and provide an engaging user experience.
  • Used Dio for efficient network requests and data retrieval.
  • Implemented GoRouter navigation, improving user flow and usability.
  • Leveraged geo services to provide location-based features relevant to hockey fans.
